JJ麻｜安心播放與電視播放器使用說明

最簡單的記法：電視安裝「JJ麻電視播放器」，女兒平板安裝「安心播放」；兩台連接同一個家用 Wi‑Fi，先開啟電視播放器，再從平板按電視圖示。

更換新電視

新電視必須使用 Android TV 或 Google TV，才能直接安裝電視播放器 APK。若不是這兩種系統，需要另外連接 Android TV／Google TV 電視盒。

  1. 新電視連接家裡的 Wi‑Fi，不要使用訪客 Wi‑Fi。
  2. 從下載頁面取得「JJ麻｜電視播放器」APK，並放進 USB 隨身碟。
  3. 將 USB 插入電視，用電視的檔案管理工具開啟 APK。
  4. 若電視詢問是否允許安裝未知應用程式，請允許目前使用的檔案管理工具安裝。
  5. 安裝後開啟「JJ麻電視播放器」，記下畫面顯示的電視位置，例如 192.168.31.164。

更換女兒的新平板

  1. 新平板連接到和電視相同的家用 Wi‑Fi。
  2. 從下載頁面安裝最新版「安心播放」。
  3. 第一次開啟時重新建立家長 PIN。
  4. 要取回白名單、收藏與觀看資料，請先在舊平板執行雲端備份，再到新平板執行雲端還原。
  5. 家長 PIN 不會隨備份轉移，需要在新平板另外設定。

第一次連接

  1. 先在電視開啟「JJ麻電視播放器」。
  2. 在平板開啟「安心播放」，按右上角電視圖示。
  3. APP 會先自動尋找電視。
  4. 如果沒有找到，在「手動輸入電視位置」填寫電視畫面顯示的數字。
  5. 按「直接連接這台電視」。成功一次後，APP 會記住位置，下次優先自動連接。

更換新電視時，平板可能先嘗試舊位置。等連接失敗後輸入新電視的位置，成功一次便會改為記住新電視。

平常使用順序

  1. 開啟電視並開啟「JJ麻電視播放器」。
  2. 開啟平板的「安心播放」，按電視圖示連接。
  3. 從平板右側或下方選擇影片；影片在電視播放，平板保留選片與控制按鈕。
  4. 結束時，在平板按「停止電視播放」。

搜尋不到或連接失敗

  1. 確認電視播放器已經開啟，並顯示電視位置。
  2. 確認電視和平板連接同一個 Wi‑Fi 名稱，且不是訪客網路。
  3. 直接輸入電視畫面目前顯示的位置，不要使用以前的舊位置。
  4. 將女兒平板的 Wi‑Fi 關閉再開啟。
  5. 關閉並重新開啟電視播放器；仍失敗再重新啟動電視和平板。

電視位置可能在重新開機或更換路由器後改變。照電視畫面輸入最新位置並成功連接一次即可。
